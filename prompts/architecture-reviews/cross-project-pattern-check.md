---
title: Prompt — Cross-Project Pattern Check
purpose: Spot reusable patterns worth extracting into a template.
---

## Prompt
```
I've now built similar {component type} in these projects: {list projects}.
Is there a common pattern worth extracting into a reusable template in
templates/? Show me the shared shape.
```

## Use When
A second or third project repeats a pattern from an earlier one.
