---
title: Prompt — Deployment Readiness Review
purpose: Confirm a project's deployment plan is real, not aspirational.
---

## Prompt
```
Review this deployment plan against docs/engineering-standards/docker.md
and mlops.md: {paste deployment plan}. Has it actually been tested, or is
it theoretical? What would fail on first real deploy?
```

## Use When
Before first production deployment of a project.
