---
title: Prompt — Revision Quiz Generator
purpose: Generate a cold-recall quiz for a concept flagged for revision.
---

## Prompt
```
Generate a 3-question revision quiz for {concept}: one definition question,
one applied/worked-example question, one business-connection question.
Don't give answers until I attempt them.
```

## Use When
A concept's confidence score drops below 3 in the learning journal.
