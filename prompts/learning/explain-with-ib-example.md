## Prompt
```
Explain {concept} in simple English. Then walk through one worked example
using an investment banking or FinTech scenario (e.g. fraud detection, credit
risk, KYC/AML). End with the one thing most people get wrong about it.
```

## Use When
Starting a new bootcamp topic in an evening or Sunday session.
