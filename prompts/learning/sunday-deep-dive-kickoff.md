## Prompt
```
I have 2+ uninterrupted hours today for {topic}. Break it into 3-4 connected
sub-parts that build on each other, and let's go through all of them in one
session with a worked example at the end tying them together.
```

## Use When
Sunday Deep Dive block for a multi-part topic.
