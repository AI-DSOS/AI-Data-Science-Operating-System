---
title: Prompt — Dataset Sourcing
purpose: Find a suitable dataset for a new portfolio project.
---

## Prompt
```
I need a dataset for {project type, e.g. fraud detection, anomaly
detection}. Suggest 2-3 realistic public options and their known
limitations (class imbalance, size, licensing).
```

## Use When
Starting a new project's data-sourcing step.
