---
title: Prompt — Multi-Tenant Consideration
purpose: Consider whether a design needs to support more than one consumer, relevant to Vaagai's multi-family model.
---

## Prompt
```
Does {system} need to support multiple tenants/families/customers from day
one, or can it start single-tenant? What would need to change to add
multi-tenancy later?
```

## Use When
Designing Vaagai-related systems or any multi-customer product.
