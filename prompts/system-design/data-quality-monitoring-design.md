## Prompt
```
Design a data quality monitoring platform: how does it detect anomalies in
incoming data, alert on drift, and expose results via API? Assume MLflow +
Prometheus + Grafana + Kubernetes as the stack.
```

## Use When
Designing or extending the Data Quality Monitoring platform.
