## Prompt
```
Design a real-time fraud detection system: ingestion, feature computation,
model serving, and alerting. Assume {transaction volume} and a latency
budget of {target}. What are the hard tradeoffs?
```

## Use When
Designing a fraud or anomaly detection portfolio project.
