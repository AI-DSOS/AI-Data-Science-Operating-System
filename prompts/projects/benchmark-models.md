## Prompt
```
For {problem type} on {dataset description}, set up a benchmark comparing
a baseline model against 3-4 stronger candidates. Report metrics honestly,
including if none hit the target — explain why, don't just tune until a
number looks better.
```

## Use When
The ML pipeline stage of a new project.
