---
title: Prompt — Scope a Project
purpose: Turn a rough idea into a scoped business-problem + requirements pair.
---

## Prompt
```
I want to build a project around {rough idea}. Help me write a business
problem statement and a requirements list (functional + non-functional),
using templates/business-problem-template.md and templates/requirements-template.md
as the shape.
```

## Use When
Before starting any new project in the 25-project library.
