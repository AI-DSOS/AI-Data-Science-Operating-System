---
title: Prompt — Architecture Tradeoff Analysis
purpose: Compare architecture options before committing, feeding an ADR.
---

## Prompt
```
I'm deciding between {option A} and {option B} for {component}. Compare them
on: complexity, cost, scalability, and fit with our existing stack. Recommend
one and draft it as an ADR using templates/adr-template.md.
```

## Use When
Any non-obvious architecture decision.
