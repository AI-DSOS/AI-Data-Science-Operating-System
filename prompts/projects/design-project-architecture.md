## Prompt
```
Design the architecture for a {project type} project solving {business
problem}. Cover: components, data flow, tech stack (per docs/engineering-standards/),
and deployment approach. Flag any non-obvious decisions that need an ADR.
```

## Use When
Starting a new project, using templates/architecture-template.md as the output shape.
