## Prompt
```
For a project that needs to {requirement summary}, recommend a tech stack
consistent with docs/engineering-standards/. For each choice, give one
sentence of why, and note if there's a simpler standard-compliant alternative.
```

## Use When
Filling out templates/tech-stack-template.md for a new project.
