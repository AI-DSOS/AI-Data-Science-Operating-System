## Prompt
```
I'm about to open a PR for {change summary}. Walk through
templates/code-review-checklist-template.md against this diff and flag
anything I'd fail if a strict reviewer looked at it.

{paste diff}
```

## Use When
Before opening any PR, solo or not.
