title: Prompt — Duplicate Content Check
purpose: Prevent writing a document that already exists, per AGENTS.md Section 5, rule 3.
---

## Prompt
```
I'm about to write a document about {topic}. Search docs/master-index.md
and resources/glossary.md — does something like this already exist? Should
I extend it instead of writing new?
```

## Use When
Before starting any new document.
