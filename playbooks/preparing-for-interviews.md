## When to Use
A real interview is scheduled — this is distinct from the regular weekly mock interview cadence.

## Steps

1. Confirm the role type (IB tech / FinTech / AI-ML consulting) and pull the matching resume variant from `docs/career-system/resume-framework.md`.
2. Review the specific job description against current skills using `prompts/career-planning/job-description-gap-analysis.md` — know the real gaps going in, don't discover them live.
3. Run a full-loop mock simulation (`prompts/mock-interviews/full-loop-simulation.md`) at least once in the 3 days prior.
4. Re-walk through the 2-3 anchor projects (per `docs/career-system/portfolio-strategy.md`) out loud — be ready for "walk me through this" without notes.
5. Refresh the 30-second pitch (`prompts/career-planning/30-second-pitch-refinement.md`).
6. Sleep and schedule permitting, avoid cramming new material the night before — revision only, no new topics.
7. Log the interview in `trackers/interview-tracker.md` before it happens, with target role and stage.
8. Within 24 hours after, draft a follow-up note (`prompts/career-planning/interview-followup-note.md`) and update the tracker with the outcome.

## Common Pitfalls

- Learning new material the night before instead of consolidating what's already there.
- Not having the anchor projects rehearsed out loud — reading about a project is not the same as explaining it under pressure.

## Checklist

- [ ] Resume variant matched to role type
- [ ] Job description gap-checked
- [ ] Full-loop mock run within 3 days
- [ ] Anchor projects rehearsed out loud
- [ ] Pitch refreshed
- [ ] Tracker updated before and after
