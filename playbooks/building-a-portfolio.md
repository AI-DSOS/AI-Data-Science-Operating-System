## When to Use
Monthly portfolio check (short version) or Quarterly Review's deeper portfolio audit (full version).

## Steps (Monthly — Short Version)

1. List every project/milestone completed since the last check.
2. For each, confirm it's reflected consistently across resume, LinkedIn, and GitHub — same claims, same numbers.
3. Fix any drift found immediately, don't defer.

## Steps (Quarterly — Full Version)

1. Run `prompts/career-planning/narrative-consistency-check.md` across resume summary, LinkedIn headline, and GitHub pinned-repo descriptions.
2. Re-evaluate the 2-3 anchor projects (`docs/career-system/portfolio-strategy.md`) — are they still the strongest, or has something newer/better replaced them?
3. Check every pinned GitHub repo still passes the publishing playbook's checklist (things can go stale — a dependency update might break the setup instructions).
4. Update the resume for any new project or skill.
5. Confirm the core narrative (QA-to-DS transition) still fits — if the story has evolved, update it everywhere at once, not gradually.

## Common Pitfalls

- Letting one channel (usually GitHub) go stale while updating the others.
- Anchor projects chosen once and never revisited even as stronger work accumulates.

## Checklist

- [ ] All channels checked for consistency
- [ ] Anchor projects still the strongest available
- [ ] All pinned repos' setup instructions re-verified working
- [ ] Core narrative confirmed still accurate
