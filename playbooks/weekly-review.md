## When to Use
End of every week (Sunday evening or Monday), per `docs/operating-system/weekly-review.md`.

## Steps

1. Copy `templates/weekly-review-template.md`.
2. Check `docs/departments/learning-mentor.md`'s phase tracker — on track or how many days behind?
3. Check active project milestone progress against `projects/README.md`'s status column.
4. Check this week's mock interview score/trend, if one was run.
5. Check content published and pipeline updates against `trackers/interview-tracker.md`.
6. Review any escalations raised mid-week that weren't resolved same-day.
7. Confirm or adjust next week's time allocation per `docs/operating-system/time-blocking.md`.
8. Save the filled template, log a one-line summary.

## Checklist

- [ ] All 4 operational departments checked
- [ ] Open escalations reviewed
- [ ] Next week's allocation confirmed
- [ ] Summary saved, even if brief
