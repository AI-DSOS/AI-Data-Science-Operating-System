# Production Checklist: [Project Name]

- [ ] Business problem and requirements documented
- [ ] Architecture documented, key decisions have ADRs
- [ ] Tests: unit, data, model, integration all present
- [ ] CI runs automatically on PR
- [ ] Deployment plan documented and tested
- [ ] Monitoring dashboard live with alerts configured
- [ ] Security checklist passed (see engineering-standards/security.md)
- [ ] Performance targets documented and measured
- [ ] README complete and accurate
- [ ] Results reported honestly, including any ceiling/negative results
