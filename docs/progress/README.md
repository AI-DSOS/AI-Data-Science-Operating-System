## Overview

This folder holds the single running record of how close DSOS is to its v1.0 targets (100 Markdown files, 25 projects, 50 templates, 100+ prompts, deployed doc site). It exists so no module ends without an honest count update.

## Update Cadence

Updated at the end of **every module** (per AGENTS.md Section 5, rule 6) — not on a calendar schedule. If a module adds files but the scorecard isn't updated in the same change, the module is not considered complete.
