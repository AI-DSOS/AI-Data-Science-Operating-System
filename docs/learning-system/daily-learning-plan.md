## Overview

`docs/operating-system/daily-operating-system.md` answers "what time blocks exist today." This document answers "what content fills them" — pulled from the current phase in `roadmap.md`.

## Weekday Evening Content Structure

A single, self-contained sub-topic from the current phase — small enough to explain, apply via one worked example, and journal in a 30–90 minute window. Never split a sub-topic that's too big for one evening across two separate evenings if avoidable; if it doesn't fit, it belongs in a Sunday Deep Dive instead.

## Sunday Deep-Dive Content Structure

2–4 connected sub-topics from the current phase, building on each other, ending in one worked example that ties them together — per `docs/operating-system/deep-work.md`'s definition of what qualifies as deep work.

## Decision Rules

- Pull today's topic from `roadmap.md`'s current phase, in the phase's natural dependency order (per `docs/learning-system/knowledge-map.md`) — not an arbitrary pick.
- If yesterday's topic wasn't fully mastered (confidence < 3), today's slot is revision of that topic, not new material, per `docs/operating-system/revision-strategy.md`.
