## Overview

Fills `templates/weekly-learning-plan-template.md` with real content decisions for the coming week, based on `roadmap.md`'s current phase and any revision carried over from the prior week.

## Weekly Content Allocation

| Session | Content Source |
|---|---|
| Mon/Wed/Fri evening | Next sequential sub-topic(s) in the current phase |
| Sunday Deep Dive 1 | The week's hardest/most multi-part topic |
| Sunday Deep Dive 2 (if used) | Portfolio project work applying the week's concepts (per `docs/departments/enterprise-project-architect.md`) |

## End-of-Week Check

At the Weekly Review (`docs/operating-system/weekly-review.md`), confirm: did the week's actual content match this plan, and is the phase tracker in `roadmap.md` still accurate? Update both if not.
